01 / INTRODUCTION

分布式系统中的通信与控制挑战

本报告模块旨在阐述网络化控制系统（NCS）在严格带宽限制下面临的核心矛盾。用户可在此了解传统“通信与控制分离”假设为何在极端条件下失效，并认识到联合通信与控制（JCC）框架的必要性。

🚫

传统方案的痛点

传统范式通常依赖于周期性数据传输和均匀的状态量化。在带宽受限时，这种盲目的传输会导致严重的量化误差、网络拥塞，最终引发物理轨迹的剧烈偏离或系统失稳。

  • • 忽略物理状态的控制关键度 (Criticality)
  • • 导致高频无用数据的堆积
  • • 在危险状态缺乏足够带宽自救
💡

JCC 协同设计解法

本课题提出针对多自由度物理信息系统的联合通信与控制（JCC）框架，专注于面向控制的数据压缩和智能传输触发。

■ 空间域：基于敏感度的加权比特分配
■ 时间域：基于深度强化学习的语用通信触发

核心目标 (Topic 6)

"Explore data compression methods that maintain control accuracy while reducing communication load."

预期结果：使用不足 20% 的通信率，达到近乎 100% 带宽的理想追踪精度。
02 / SPATIAL COMPRESSION

基于 LQR 敏感度的加权数据压缩

本模块展示空间域的数据压缩策略。用户可通过交互图表对比“均匀压缩”与“LQR加权压缩”在带宽分配和最终物理控制代价上的巨大差异。核心思想：不是所有自由度都一样重要。

信道带宽分配对比 (总预算: 16 bits)

传统均匀分配将带宽平均分配给所有关节，忽略了底座关节的微小误差会引发巨大的末端偏移。

面向控制的失真代价 (Control Cost)

代价公式: $J = x^T Q x$，越低表示控制精度越高。

🚀 性能跃升：在相同极低带宽下，LQR 加权分配通过保全高敏感度状态，将整体控制代价降低了近 80%。

算法原理摘要

算法通过求解离散时间代数 Riccati 方程 (DARE)，提取系统矩阵和代价矩阵的内在联系，生成敏感度矩阵 (Hessian Matrix $P$)。

bi = Btotal/n + 0.5 * log2 ( Pii * σi2 / GeometricMean )

该率失真(Rate-Distortion)公式使得通信信道能够根据不同状态变量的“控制关键性”动态分配比特，显著减轻了量化引发的性能退化。

03 / TEMPORAL COMPRESSION

基于 DQN 的智能事件触发机制

本模块揭示时间域上的极致压缩。用户将观察到强化学习智能体（DQN）如何学会“语用通信”：打破固定周期发送的死板规则，仅在物理轨迹即将失控的关键时刻触发数据传输。

轨迹追踪与通信条形码 (仿真演示)

展示系统状态随时间推移的控制精度及对应的通信时机。

1. 状态轨迹 (State Trajectory)

2. 通信触发条形码 (Communication Barcode)

竖线代表在该时间步(Time Step)执行了一次数据传输。DQN 智能体学会了在初始偏差大时密集发送，平稳后保持沉默。

🧠 算法核心：边缘样本挖掘与语用通信

强化学习奖励函数设计为：R = -(追踪误差) - λ * (发送动作 0或1)。通过在训练阶段引入边缘状态采样 (Hard Negative Mining)，克服了状态空间不平衡问题，有效防止智能体为了节省带宽而陷入过度保守（导致系统发散）的次优策略。

04 / ROADMAP

进阶演进：多智能体带宽博弈与 NMPC

本部分概述项目向更复杂现实场景演进的实施规划。为彻底契合 Topic 6（分布式智能体协调），提出将多智能体强化学习（MARL）与非线性模型预测控制（NMPC）深度结合的高阶方案。

1

确立 NMPC 物理上限

使用 PyBullet 与 CasADi 构建非线性多自由度机械臂。NMPC 因具备“预测未来”能力，能更好地容忍粗糙的量化数据，作为高阶控制核心。

2

构建连续动作空间 (MAPPO)

从简单的 DQN (0或1) 升级至 MAPPO。机械臂的每个关节作为一个 Agent，输出连续的带宽优先级请求 $a_i \in (0,1]$。

3

动态带宽博弈机制

基于 Softmax Allocation 将连续动作转化为实际分配比特。所有智能体共享全局 NMPC 惩罚作为 Reward，学会在重力扭矩极大等危险期互相让渡带宽。

🚀

终极愿景展现

在最终展现中，3D环境内的多个分布式实体将共享极度拥挤的信道。随着系统状态变化，底层通信网络将展现出“呼吸效应”——动态、非均匀且精准的带宽堆叠分配，完美诠释分布式智能体协调中的 JCC 协同设计理念。
